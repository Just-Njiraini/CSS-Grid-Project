# CSS-Grid-Project

A CSS Grid project recreating Piet Mondrian's abstract geometric artwork using HTML and CSS. Focused on mastering CSS Grid layouts, positioning, sizing, and responsive design.

**Overview**

This project recreates a geometric composition inspired by the artwork of Piet Mondrian using HTML and CSS Grid.

The primary objective was to develop a practical understanding of CSS Grid and explore how rows, columns, gaps, and grid positioning can be used to create complex layouts.

**Technologies Used**
HTML5

CSS3

CSS Grid

**What I Learned**

-Creating layouts using display: grid.

-Defining columns and rows using grid-template-columns and grid-template-rows.

-Controlling element positioning within a grid.

-Using CSS Grid to create geometric compositions.

-Working with background colours, spacing, and proportions.

-Structuring HTML elements to achieve a desired visual layout.

**What I Would Improve**

This project is part of my ongoing journey in frontend development. Future improvements could include experimenting with more complex grid layouts, responsive behaviour, and additional CSS techniques.
